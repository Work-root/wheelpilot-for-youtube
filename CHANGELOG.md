# Changelog

All notable changes to WheelPilot for YouTube are documented here.

## [0.2.3] - 2026-08-24

### Changed

- Updated the public product branding to WheelPilot for YouTube.
- Settings exports now use the WheelPilot name while remaining compatible with
  backups created by earlier releases.
- Store links now use the permanent Chrome Web Store item ID.

## [0.2.2] - 2026-08-24

### Added

- Interactive first-run tour in English, Russian, Spanish, and Korean.
- GitHub and direct Telegram support links in the popup footer.
- Localized extension name, description, action title, and shortcut descriptions.

### Changed

- Mouse-wheel speed control now covers the complete YouTube time display.
- The tour introduces wheel zones, adjustable boundaries, timeline speed control,
  video zoom, player tools, and speed-aware remaining time.
- Completed live-stream recordings use the normal elapsed, duration, and
  speed-adjusted remaining-time display.
