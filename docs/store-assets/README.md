# Chrome Web Store assets

Готовые PNG-файлы предназначены для черновика карточки Chrome Web Store.
Исходники находятся в `sources/` и выполнены в SVG, чтобы их можно было
обновлять без потери качества.

Перед окончательной загрузкой сравните скриншоты с финальной сборкой
расширения. Если интерфейс или формулировки изменились, изображения необходимо
пересобрать.

Набор:

- `store-icon-128.png` — магазинный значок с безопасным прозрачным полем;
- `promo-small-440x280.png` — обязательная промо-плитка без текста;
- `promo-marquee-1400x560.png` — опциональный большой баннер;
- `screenshot-1-wheel-zones-1280x800.png` — управление колесом и границы зон;
- `screenshot-2-timeline-speed-1280x800.png` — изменение скорости над временем;
- `screenshot-3-settings-1280x800.png` — popup и основные настройки.

Для пересборки SVG в PNG используется Chrome в headless-режиме с масштабом 1.
