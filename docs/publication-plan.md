# План публикации WheelPilot for YouTube

Текущая версия расширения: `0.2.3`.

## Правильная очередность

### 1. Зафиксировать адреса проекта

1. Обновить отображаемое название Telegram-канала на WheelPilot for YouTube.
2. Оформить аватар, краткое описание и постоянный `@username`.
3. Опубликовать приветственный пост, краткую инструкцию и пост поддержки.
4. Включить платные реакции у поста поддержки и закрепить его.
5. Сохранить прямую ссылку на пост поддержки.
6. Зарегистрировать учётную запись разработчика Chrome Web Store и создать
   черновик карточки расширения. Это нужно сделать рано, чтобы получить ID
   расширения до финальной сборки.

Канал создаётся до финального ZIP, потому что ссылка на закреплённый пост будет
зашита в `config.js`. Черновик магазина создаётся до ZIP, потому что ID нужен
для правильной ссылки кнопки «Оценить» в `config.js`.

### 2. Привести репозиторий в релизный вид

1. Добавить стабильные документы: `PRIVACY.md`, лицензию, журнал изменений и
   понятный способ связи/сообщения об ошибке.
2. Сделать GitHub главным публичным сайтом проекта: описание, реальные
   скриншоты, установка из магазина, возможности, разрешения и приватность.
3. Проверить прямую ссылку на закреплённый пост канала в `config.js`.
4. Подставить полный URL карточки магазина с настоящим ID в `config.js`.
5. Поддерживать manifest-локализацию через `_locales/en`, `_locales/ru`,
   `_locales/es`, `_locales/ko` и `default_locale`.
6. Проверить, что название, логотип и формулировки одинаковы в расширении,
   GitHub, Telegram и магазине.
7. Не включать в ZIP исходные генерации логотипа, резервные копии, тесты и
   посторонние изображения.

### 3. Провести релизную проверку

1. Запустить все автоматические тесты и `node --check` для JavaScript-файлов.
2. Установить чистую распакованную сборку в отдельный профиль Chrome.
3. Проверить обычное видео, детский канал без рекламы, рекламу, прямой эфир с
   DVR, полноэкранный режим и переходы YouTube без перезагрузки страницы.
4. Проверить колесо над левой/правой зонами, временем, ЛКМ + колесо,
   приближение и перетаскивание границ знакомства.
5. Проверить RU/EN/ES/KO, светлую/тёмную тему, кнопку Telegram и кнопку оценки.
6. Убедиться, что расширение не выполняет удалённый код и не отправляет данные.
7. Собрать ZIP только из релизной папки и повторно установить именно этот ZIP.

### 4. Опубликовать GitHub-релиз

1. Обновить README и CHANGELOG для версии `0.2.3`.
2. Закоммитить релизные изменения.
3. Создать тег `v0.2.3` и GitHub Release.
4. Приложить тот же ZIP, который будет отправлен в Chrome Web Store.
5. В релизе дать ссылку на политику конфиденциальности и Telegram-канал.

GitHub публикуется перед отправкой в магазин: проверяющий и пользователь уже
увидят рабочую домашнюю страницу, поддержку, историю версии и политику.

### 5. Заполнить Chrome Web Store и отправить на проверку

1. Категория: **Make Chrome yours / Functionality & UI**
   (**Персонализируйте Chrome / Функции и интерфейс**). Это точнее отражает
   добавляемые в YouTube жесты, зоны и элементы управления, чем общая категория
   «Работа и планирование».
2. Загрузить значок 128×128, минимум один скриншот 1280×800 и обязательную
   промо-плитку 440×280. Рекомендуется загрузить 3–5 скриншотов и опциональную
   плитку 1400×560.
3. Домашняя страница: репозиторий GitHub.
4. Поддержка: GitHub Issues; Telegram указать дополнительно в описании и
   интерфейсе, но не делать единственным местом для сообщений об ошибках.
5. Политика конфиденциальности: постоянная ссылка на `PRIVACY.md` в ветке
   `main` или GitHub Pages.
6. Во вкладке приватности указать одну цель расширения, обосновать `storage` и
   доступ к `youtube.com`, отметить отсутствие удалённого кода и отсутствие
   сбора пользовательских данных.
7. Сначала использовать доверенных тестировщиков, если они есть; затем
   отправить публичную версию. Если доступна отложенная публикация, включить
   её, чтобы самому выбрать момент запуска после одобрения.

### 6. Объявить запуск после фактического одобрения

1. Установить расширение из магазина в чистый профиль и повторить короткий
   smoke-тест.
2. Проверить кнопки «Поблагодарить» и «Оценить» уже в магазинной сборке.
3. Обновить README: заменить раздел ручной установки основной кнопкой
   «Установить из Chrome Web Store»; ручную установку оставить для разработки.
4. Опубликовать в Telegram пост о запуске со ссылками на магазин, GitHub и
   список главных возможностей.
5. Закрепить приветственный/релизный пост, а пост поддержки оставить доступным
   по прямой ссылке из расширения.

Не публиковать громкий анонс до одобрения магазина: иначе первые пользователи
получат неработающую ссылку или инструкцию с режимом разработчика.

### 7. Первые две недели после запуска

- Ежедневно проверять отзывы магазина, GitHub Issues и комментарии Telegram.
- Отслеживать отклонения, удаления расширения и повторяющиеся проблемы.
- Исправлять критические ошибки отдельными патчами, не меняя
  сразу крупные функции.
- Через 7–14 дней попросить довольных пользователей поставить оценку, без
  награды и без блокирования интерфейса.
- Вести CHANGELOG и публиковать короткий Telegram-пост на каждый релиз.

## Материалы Chrome Web Store

Официальные требования на момент подготовки:

| Материал | Размер | Статус |
| --- | --- | --- |
| Значок магазина | 128×128 PNG | обязателен |
| Скриншоты | 1280×800 или 640×400, от 1 до 5 | обязательны |
| Малая промо-плитка | 440×280 PNG/JPEG | обязательна |
| Большая промо-плитка | 1400×560 PNG/JPEG | опциональна, нужна для выделения |
| YouTube-видео | ссылка | опционально |

Значок должен хорошо смотреться на светлом и тёмном фоне. Для квадратного
значка Google рекомендует оставлять примерно 16 пикселей прозрачного поля с
каждой стороны. Скриншоты должны показывать реальный интерфейс текущей версии,
иметь квадратные углы и заполнять кадр без внешних отступов. Промо-плитка — это
брендовый рисунок, а не просто снимок экрана; текста на ней должно быть мало
или не быть совсем.

Подготовленный набор находится в `docs/store-assets/`:

- `store-icon-128.png` — вариант значка с безопасным полем;
- `promo-small-440x280.png` — обязательная малая плитка без текста;
- `promo-marquee-1400x560.png` — опциональная большая плитка;
- `screenshot-1-wheel-zones-1280x800.png` — главное достоинство, колесо;
- `screenshot-2-timeline-speed-1280x800.png` — скорость над всей полосой времени;
- `screenshot-3-settings-1280x800.png` — реальные настройки popup.

Перед загрузкой изображения нужно сравнить с финальной магазинной сборкой.
Если интерфейс изменился, скриншоты переснять: магазин требует актуальный
пользовательский опыт.

## Полное описание для русской карточки

> WheelPilot for YouTube позволяет управлять самыми частыми действиями прямо
> колесом мыши над плеером. Наведите курсор на левую часть видео для перемотки,
> на правую — для громкости, на строку времени — для изменения скорости без
> нажатия кнопок −/+, или удерживайте левую кнопку мыши и крутите колесо.
>
> Основные возможности:
>
> • настраиваемые колёсные зоны плеера;
> • скорость от 0,1× до 16× и шесть быстрых пресетов;
> • скорость над всей строкой времени YouTube;
> • приближение видео колесом и перемещение увеличенного кадра;
> • запоминание скорости отдельно для каждого канала;
> • покадровый шаг, повтор A–B и скриншот кадра;
> • ускорение рекламы и возвращение к выбранной скорости после неё;
> • режим прямых эфиров с догоняющим воспроизведением;
> • экспорт и импорт настроек;
> • интерактивное знакомство с возможностями расширения.
>
> Все действия выполняются локально в браузере. Расширение не собирает
> аналитику, историю просмотров или персональные данные, не отправляет данные
> разработчику и не использует удалённый код.

## Текст для проверки приватности

**Единственная цель**

> Расширение добавляет на YouTube локальные элементы и жесты управления
> воспроизведением: скорость, перемотку, громкость, масштаб и вспомогательные
> инструменты плеера.

**Разрешение `storage`**

> Используется только для сохранения настроек расширения, выбранного языка,
> пресетов и скоростей каналов через `chrome.storage.sync`.

**Доступ к `*.youtube.com`**

> Нужен для добавления элементов управления на страницу YouTube и применения
> выбранной пользователем скорости, громкости, перемотки и масштаба к плееру.

**Удалённый код**

> Нет. Весь исполняемый JavaScript включён в ZIP расширения.

**Данные пользователей**

> Расширение не собирает, не передаёт и не продаёт пользовательские данные.
> Настройки хранятся только средствами Chrome.

## Что часто забывают

- Одно и то же название издателя во всех местах.
- Настоящий ID магазина в кнопке оценки до сборки ZIP.
- Manifest-локализацию, а не только переводы popup.
- Постоянную политику конфиденциальности и способ сообщить об ошибке без
  Telegram.
- Лицензию исходного кода и CHANGELOG.
- Проверку ZIP после упаковки, а не только рабочей папки.
- Отсутствие лишних файлов и секретов в архиве.
- Тест обновления поверх предыдущей версии без потери настроек.
- Резервное владение аккаунтами GitHub, Google и Telegram.
- Региональные ограничения Chrome Web Store, Telegram Stars и Fragment.
