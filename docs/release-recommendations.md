# Итоговые рекомендации по публикации

Дата фиксации: 15 августа 2026 года.

## Главное решение

- Обновить отображаемое название Telegram-канала на WheelPilot for YouTube.
- Использовать платную реакцию ⭐ под отдельным закреплённым постом как основной
  способ благодарности.
- Оставить подарок каналу 🎁 дополнительным памятным способом поддержки.
- Не разрабатывать бота: для выбранного сценария он не нужен.
- Не использовать личный Telegram-аккаунт как основной адрес проекта.

## Рекомендуемая последовательность

1. Создать Telegram-канал, занять постоянный `@username` и оформить профиль.
2. Опубликовать приветственный пост, инструкцию и закреплённый пост поддержки.
3. Включить платные реакции и получить прямую ссылку на пост поддержки.
4. Создать черновик Chrome Web Store, чтобы заранее получить ID расширения.
5. Проверить ссылку Telegram и подставить настоящий URL магазина в `config.js`.
6. Добавить manifest-локализацию RU/EN/ES/KO, лицензию и CHANGELOG.
7. Провести автоматические и ручные проверки финального ZIP.
8. Опубликовать GitHub Release с тем же ZIP, который отправляется в магазин.
9. Заполнить карточку Chrome Web Store и отправить расширение на проверку.
10. После одобрения установить магазинную сборку и провести smoke-тест.
11. Только после успешной проверки опубликовать Telegram-анонс и основную
    ссылку магазина в README.

## Позиционирование расширения

Главное достоинство следует показывать первым во всех описаниях и
изображениях: управление YouTube колесом мыши непосредственно над плеером.

Порядок преимуществ:

1. Колёсные зоны: перемотка слева и громкость справа.
2. Изменение скорости колесом над всей строкой времени без нажатия `−/+`.
3. ЛКМ + колесо для скорости над видео.
4. Приближение видео колесом и перемещение увеличенного кадра.
5. Настраиваемые границы зон и интерактивное знакомство.
6. Скорости каналов, прямые эфиры, кадры, повтор A–B и скриншоты.

Не следует начинать карточку с общего обещания «удобное управление
скоростью»: оно не объясняет уникальное преимущество продукта.

## Chrome Web Store

- Категория: **Productivity / Продуктивность**.
- Домашняя страница: репозиторий GitHub.
- Поддержка и сообщения об ошибках: GitHub Issues.
- Telegram: сообщество, новости и добровольная благодарность.
- Политика конфиденциальности: постоянная ссылка на `PRIVACY.md`.
- Удалённый код: отсутствует.
- Сбор и передача пользовательских данных: отсутствуют.
- `storage` используется только для настроек через `chrome.storage.sync`.
- Доступ к `youtube.com` используется только для управления плеером.

Готовые материалы магазина находятся в `docs/store-assets/`. Первым
скриншотом должна быть карта колёсных зон, вторым — скорость над таймлайном,
третьим — popup. Это соответствует реальному приоритету продукта.

## Telegram и распоряжение поддержкой

- Канал получает звёзды от платных реакций на баланс канала.
- Заработанные звёзды становятся доступными для вывода через 21 день.
- Вывод выполняет владелец через Fragment на TON-кошелёк.
- Текущий минимальный порог в интерфейсе Telegram — 1000 звёзд; Telegram может
  изменить его.
- Вместо вывода звёзды можно использовать для рекламы в Telegram со скидкой.
- Баланс звёзд канала нельзя произвольно перевести на личный баланс.
- Полученные каналом подарки можно передавать, но их стоимость и ликвидность
  непредсказуемы. Поэтому подарок не должен быть основным способом доната.
- Поддержка должна быть добровольной и не открывать функции расширения.

## Что нельзя упустить

- Включить 2FA и восстановление для Google, GitHub и Telegram.
- Добавить резервного администратора канала, не передавая ему владение без
  необходимости.
- Проверить обновление поверх предыдущей версии без потери настроек.
- Проверять именно собранный ZIP, а не только рабочую папку.
- Не включать в ZIP исходные генерации изображений, тесты, резервные копии и
  секреты.
- Не публиковать громкий анонс до фактического одобрения Chrome Web Store.
- Не обещать пользователям, что подарок или звезда равны фиксированной сумме
  денег: курс, комиссии и региональные ограничения меняются.
- Первые две недели после запуска ежедневно просматривать отзывы, Issues и
  сообщения канала; критические исправления выпускать отдельными патчами.
