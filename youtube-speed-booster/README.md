# WheelPilot for YouTube

Исходники Chrome-расширения (Manifest V3, без сборщиков и зависимостей).

Полная документация проекта — в корне репозитория:

- `../README.md` — описание функций, структура, ключи storage, архитектура;
- `../UX-ANALYSIS.md` — UX-анализ и принятые проектные решения.

Установка: `chrome://extensions` → Developer mode → Load unpacked → выбрать эту папку.
